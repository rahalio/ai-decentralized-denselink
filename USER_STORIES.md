# Denselink — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Mobile developer

- As a developer, I want a license key and MeshPort in minutes, so that I ship mesh features without forking the shared service.
- As a developer, I want to see nearby density from other apps, so that I launch first in regions where piggybacking already works.

### Developer relations manager

- As a DevRel manager, I want to rank projects by density contribution, so that grants go to apps that grow the commons.
- As a DevRel manager, I want private-beta cohort metrics (80 projects), so that we time public beta when collision and density risks are controlled.

### Venue operator

- As a stadium operator, I want a density dashboard on event days, so that sponsors see mesh availability for offline apps.
- As a school IT lead, I want wedge deployment playbooks, so that student devices contribute safe, licensed mesh density.

### Analytics lead

- As an analytics lead, I want Dhaka-vs-SF model comparisons for our launch city, so that penetration targets are realistic.
- As an analytics lead, I want heatmaps at 80–100m granularity, so that gap-fill grants target dead zones.

### Finance / incentives admin

- As an incentives admin, I want grants released on density milestones, so that token/staking budgets align with network effects.

### Platform administrator

- As a platform administrator, I want to revoke a license key when MeshPort abuse is detected, so that one bad app cannot intercept mesh traffic.
- As a platform administrator, I want negative-path alerts when encryption attestation fails for a build, so that Signal-protocol promises are not hollow.
